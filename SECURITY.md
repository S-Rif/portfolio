# Sécurité

Ce dépôt est un portfolio pédagogique sur un fil rouge fictif. Il ne contient ni service en production, ni donnée réelle, ni secret.

## Signaler un problème

Utilise le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**. Ne publie pas de détail dans une issue publique.

Sont concernés en priorité : un secret ou une donnée personnelle présents dans le dépôt ou son historique, et un workflow qui donnerait des droits excessifs.
