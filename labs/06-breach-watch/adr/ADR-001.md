# ADR-001 · Où vérifier un mot de passe

- **Statut** : proposé
- **Lab** : 06 · Breach Watch

## Contexte

L'application propose de vérifier si un mot de passe figure dans des fuites connues. Ce seul geste peut transformer l'outil en collecteur de mots de passe.

## Options

| Option | Coût | Avantages | Limites |
| --- | --- | --- | --- |
| Côté navigateur, k-anonymat | 0 € | Le mot de passe ne quitte pas l'appareil | Code client à auditer |
| Côté serveur, k-anonymat | 0 € | Code centralisé | Le serveur voit le mot de passe |
| Base locale complète des empreintes | Stockage important | Aucune requête externe | Volume, mises à jour |

## Décision

Vérification côté navigateur : seuls les 5 premiers caractères de l'empreinte SHA-1 sortent ; le serveur Breach Watch ne voit jamais ni le mot de passe ni l'empreinte.

## Conséquences

- (+) Argument fort en entretien : vie privée par conception, vérifiable par un test.
- (−) Fonction indisponible sans JavaScript.

## Déclencheur de revue

Exigence client de fonctionnement hors ligne ou interdiction des appels externes.
