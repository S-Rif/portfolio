# ADR-001 · Moteur de conteneurs du poste

- **Statut** : proposé
- **Lab** : 00 · Environnement

## Contexte

Tous les labs reposent sur des conteneurs. Le poste est un Windows 11 avec WSL2, et le parcours doit rester à 0 € de licence.

## Options

| Option | Coût | Avantages | Limites |
| --- | --- | --- | --- |
| Docker Engine dans WSL | 0 € | Natif Linux, léger, proche des serveurs | Service à gérer soi-même |
| Docker Desktop | Licence payante en entreprise au-delà d'un seuil (à vérifier) | Interface, intégration Windows | Consommation mémoire, licence |
| Podman | 0 € | Sans démon, sans root | Écarts de compatibilité avec Compose |

## Décision

Docker Engine installé dans WSL, démarré par systemd.

## Conséquences

- (+) 0 €, comportement identique aux runners GitHub Actions.
- (−) Pas d'interface graphique : tout se fait en ligne de commande.

## Déclencheur de revue

Exigence client de conteneurs sans root, ou poste géré imposant Docker Desktop.
